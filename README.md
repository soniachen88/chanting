# 念經次數

這是一個記「今天念了幾遍」的小網頁。打開就能看經文、按一下加上一遍，也看得到今天的進度、累計遍數，和連續達標幾天。

預先放了兩部經，每天的目標都是 7 遍：

- 《太陽星君聖經》
- 《太陰星君聖經》

經文可以自己新增、修改、刪除。目標遍數也能改。資料存在這台手機的瀏覽器裡，不會上傳。

網址：<https://soniachen88.github.io/chanting/>

請用 iPhone 的 **Safari** 打開。

## 加入 iPhone 主畫面

1. 用 Safari 打開上面的網址。
2. 點下方的分享按鈕（一個方框，裡面有向上的箭頭）。
3. 往下捲，點「加入主畫面」。
4. 名稱保持「念經」即可，再點右上角「加入」。
5. 之後從主畫面的「經」圖示打開。

請先在有網路時打開過一次。之後沒有網路，多半還是開得了。若開不起來，連上網再開一次即可。

建議固定從主畫面圖示開啟。換手機、或清除 Safari 網站資料之前，請先備份。

## 備份與還原

1. 首頁點「備份還原」。
2. 點「匯出備份」。iPhone 會跳出分享畫面，請選「儲存到檔案」，或用 AirDrop、郵件、訊息傳給自己。
3. 換手機後，用 Safari 打開同一個網址，到「備份還原」，點「匯入備份」，選剛才那個 JSON 檔，再確認取代。

備份檔就是一份文字檔，請把它留在「檔案」或傳給自己。只存在網頁裡的紀錄，清掉瀏覽資料就沒有了。

## 每天怎麼用

- 點經名可以看全文。念完按底下的「念完一遍 +1」。
- 按錯了，按「撤銷 −1」。
- 卡片上的「念完 +1」不用打開全文也能記。
- 「每日紀錄」可以看每一天念了幾遍，也能補記或修改某一天。
- 連續達標：連續幾天都有念滿當天的目標。今天若還沒念完，先從昨天往回算，不會一早就算斷掉。日期以台北時間為準。
